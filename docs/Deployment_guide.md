All of our services are deployed on AWS cloud infrastructure, and the architecture takes advantage of several important cloud computing characteristics, including resource pooling, elasticity, and on-mand self-service. Instead of managing physical infrastructure, we can provision and use cloud resources whenever they are needed.

Our system follows a complete data pipeline:
Sensor data is first generated by our sensor simulator and sent to the cloud through API Gateway. The data is then processed by Lambda, stored in DynamoDB, email alerts are triggered through SNS when necessary, and finally the processed information is presented to users through our EC2 dashboard and S3 citizen portal.
